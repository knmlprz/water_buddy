# water_buddy

Strona jest w `github/fieldtwin6767/frontend`. Z tego katalogu, w kontenerze Jazzy (`./scripts/setup.bash jazzy`):

```bash
npm run dev
```

Adres: http://localhost:3000

Klawisze `1`, `2`, `3` i strzałki zmieniają ekran. Spacja na sezonie odtwarza tygodnie.

Gdy brakuje katalogu `node_modules` w froncie, raz:

```bash
npm ci --prefix github/fieldtwin6767/frontend
```
